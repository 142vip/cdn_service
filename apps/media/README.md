# media

自媒体宣传相关静态资源，主要用于公众号等平台。

## 目录说明

| 目录 | 说明 |
| --- | --- |
| [svg](./svg) | 通用 SVG 图标（GitHub、Bilibili、掘金、`vip-logo`、`x-logo` 等） |
| [icons](./icons) | 站点 favicon（`.ico`） |
| [wechat](./wechat) | 微信公众号二维码及配图 |

变更后执行 `pnpm sync:cdn` 可同步至 `@142vip/cdn`（如 `MEDIA_SRC.svg.xLogo`、`MEDIA_SRC.icons.vipFavicon`）。
